# When to ask in spike sorting

Choose the next operation on the current cluster state. Request guidance when
uncertain evidence could change a consequential split or merge. Check with the
adviser before discarding a cluster in the collaborative pilot. If discard is
unconfirmed or the query budget is exhausted, preserve the spikes for review.

Use waveform shape and stability, ISI contamination, and the split or merge
evidence together. A small cluster or high apparent confidence alone is weak
evidence. Continue independently on other clusters after an abstention.
